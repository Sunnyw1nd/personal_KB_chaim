## 克隆后使用

按 README 安装，然后自行创建 `samples/` 并放入合法保存的文章ZIP；需要图片功能时自行准备
`test_pictures/`和标注工作簿。密钥从空模板复制到本机`.env`后填写，绝不提交。
普通单元测试可运行，真实样本回归会在样本缺失时跳过；云端调用仍要求明确允许外发。

未来若要发布真实样本、人工答案或局域网实验，先核查授权、隐私、内容许可和配置，采用独立的
脱敏资料或实验版本，不直接解除整个数据目录的忽略。本次不自动给第三方素材添加开源许可，
也不替项目所有者选择项目代码许可证。

## 发布前验证

先从Git暂存区生成不含任何本机资料的源码副本，再运行测试。初次检查发现系统Git的
`core.autocrlf=true`会把Prompt改为CRLF，使两项冻结哈希校验失败；`.gitattributes`固定Markdown
为LF后重测，既不修改提示词内容，也不重算冻结身份。这条规则还适用于实验Prompt。

敏感扫描检查暂存内容与本机`.env`值是否相同，同时扫描Token/私钥/图片Base64/私有部署地址。
匹配到的Token样式仅存在于人工构造的脱敏单元测试，例如顺序字母数字串，不是有效凭据；保留
这些测试以验证安全规则。真实`.env`及完整响应不会进入提交历史。

最终源码副本检查：`python -m pytest -ra`为163 passed、6 skipped（5项缺少真实样本、1项无法创建
符号链接）；两个公开实验的测试为27 passed。Ruff检查通过，69个Python文件格式检查通过；
暂存差异检查通过。109个文件约1.1MB，暂存内容没有匹配本机密钥、私钥、完整图片Base64或私有
部署地址。未调用模型，也没有下载或上传真实样本。
